# Agenda São Paulo

Página estática com curadoria de programas em São Paulo para família e casal.

## Publicação no GitHub Pages

1. Crie um repositório chamado `agenda-sp`.
2. Envie `index.html`, `.nojekyll` e `README.md` para a branch `main`.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione **main** e **/(root)** e salve.
6. Aguarde a publicação e abra a URL indicada pelo GitHub Pages.

## Atualizações

Nas próximas versões, substitua o arquivo `index.html` pela nova agenda gerada, mantendo o mesmo nome. O endereço público do site permanece o mesmo.
